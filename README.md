# Tomasz Różański personal webpage

This repository hosts a fresh static version of my personal webpage at
`rozanskit.com`.

The current direction is intentionally simple:

- hand-written HTML, CSS, and small amounts of vanilla JavaScript;
- no framework, static site generator, package manager, or build step by
  default;
- compact content focused on current research, selected papers, profile links,
  and a small apps section;
- English and Polish pages may be asymmetric rather than forced translations;
- legacy material is treated as reference, not as architecture to preserve.

The site can grow gradually: blog posts, equations, small frontend apps, and
scientific or educational demos are welcome when there is real content for them.
When adding pages, keep navigation honest, update metadata and sitemap/RSS files
when useful, and check the rendered layout on phone, tablet, laptop, and desktop
viewport sizes.

SUPPNet currently remains an external online demonstration linked from the apps
section rather than being rebuilt inside this repository.
